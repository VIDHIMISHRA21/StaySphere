# StaySphere - Hotel Booking System

StaySphere is a modern hotel booking web application inspired by platforms like Goibibo. It allows users to search, explore, and book hotels through a clean and responsive interface.

## Features
- Hotel search
- Booking system
- Login/Register
- Responsive UI

## Tech Stack
- React (Frontend)
- PHP (Backend)
- MySQL (Database)

## How to Run

### Frontend
cd frontend
npm install
npm run dev

### Backend
Start XAMPP (Apache + MySQL)
